# REQ03 — Exhibit & Learning Flow

**Teacher exhibit:** create a draft → edit or preview → publish → archive if needed → restore to the museum. A draft can be deleted. Only drafts are editable; a correction to a published exhibit requires a new draft. Archived exhibits leave public browsing while earlier attempts and statistics remain.

**Student attempt:** read the wrong solution → choose the mistake → optionally explain the choice → submit once → reveal choice-specific feedback and the corrected explanation → try again for practice. Practice does not overwrite the first saved answer; older exhibits without choice-specific feedback use the general explanation.

**AI code challenge:** choose Fix the AI in the JavaScript room → request a challenge → select the mistake **or** correct one code line → check the answer and read the explanation → request another challenge. The backend validates generated challenges and can return a reviewed challenge if generation fails. Code edits are compared as text, not run.

A teacher exhibit contains a question, wrong solution, 2–6 answer choices, one correct choice, feedback per choice, and an explanation.
