# REQ03 — Exhibit & Attempt Flow

**Teacher:** create a complete draft → edit or preview it → publish it to a room → optionally archive it. Only drafts can be edited. Published exhibits are read-only; a correction requires a new exhibit. Archived exhibits leave the public museum, while existing attempts and statistics remain.

**Student:** view the question and wrong solution → choose where the reasoning failed → submit the first answer → reveal choice-specific feedback and the correct solution. Submitting again does not replace the stored first answer. Older exhibits without choice-specific feedback show the general explanation.

Each new teacher exhibit includes a question, wrong solution, 2–6 answer choices, one correct choice, feedback for each choice, and a corrected solution with explanation.
