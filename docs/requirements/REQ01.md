# REQ01 — Product & Features

**Almost** is a shared Museum of Mistakes. Everyone can browse the published Math and JavaScript rooms. Each exhibit shows a question, a deliberately incorrect solution, and choices about where the reasoning went wrong.

- **Student:** registers, explores teacher exhibits, saves one first answer per exhibit version, sees feedback and the corrected explanation, then can try again for practice without changing the saved answer.
- **Teacher:** registers, creates and previews exhibits, manages their publication, and sees anonymous answer summaries for exhibits they own.
- **Fix the AI:** in the JavaScript room, signed-in users can choose between teacher exhibits and short AI code challenges. They identify the mistake or correct a line; a reviewed challenge may be used if live generation fails.
- **Account:** student/teacher registration, login, profile, and email password reset when email delivery is configured.

The museum is shared across users. Classes, student-submitted mistakes, and teacher review queues are outside this demo.
