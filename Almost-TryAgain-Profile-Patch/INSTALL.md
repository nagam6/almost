# Almost — Try again & Profile

انسخي محتويات مجلد `apps` من هذه الحزمة إلى مجلد `apps` في مشروعك، ووافقي على استبدال الملفات الأربعة المطابقة فقط. لا تنسخي مجلد الحزمة نفسه داخل المشروع.

أول إجابة تُحفظ. Try again تدريب غير محفوظ، والنتيجة الأولى تعود بعد تحديث الصفحة. البروفايل يوجّه حسب الدور، ويستخدم صفحة Forgot Password الحالية لتغيير كلمة السر عبر البريد.
